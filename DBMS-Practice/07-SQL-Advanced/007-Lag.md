# Lag

## Scenario
Analytics wants day-over-day change in daily active users: for each day, show the difference from the previous day's count.

## Solution
```sql
SELECT
    day,
    dau,
    dau - LAG(dau) OVER (ORDER BY day) AS change_from_prev_day
FROM daily_active_users
ORDER BY day;
```

`LAG(dau)` looks at the value of `dau` from the **previous row** in the ordered window (default offset 1) - for the very first day, `LAG` returns `NULL` (no previous row exists), so `change_from_prev_day` is `NULL` there, which is correct - there's no "previous day" to compare against.

## Takeaway
`LAG()` gives you access to a prior row's value without a self-join - essential for period-over-period comparisons (day-over-day, month-over-month) directly in SQL.
